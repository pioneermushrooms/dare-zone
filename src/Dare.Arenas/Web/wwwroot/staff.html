Server commands

Every command the zone has loaded right now, with its help. Type them in game chat with ? (or * for some). Send one to a pilot as a private message (/?command) to aim it at them.

How do I…

Stop or change a message the zone keeps repeating
Open the Arena Editor, pick Public (0) (or the arena it repeats in), then Messages. Switch the timed message off or remove it. In game, in that arena: ?seta Misc:PeriodicMessage0=0 (no spaces around : or =).
Change an arena's rules, ships, weapons or prizes
Arena Editor → pick the arena → Settings, then a tab (Ships, Weapons, Prizes and buying, Game rules, Flags and balls). Sysops and smods can edit every arena, including Public (0).
Change a zone-wide setting
In game, as sysop: ?getg Section:Key to read it, ?setg Section:Key=value to change it (written to global.conf; no spaces around : or =). Some need a zone restart.
See what the server has been warning about
?lastlog shows recent log lines; ?lastlog 50 Security filters by module. Red sysop messages are Malicious or Error logs.
Deal with a pilot
/?kick, /?spec, /?info (sent privately to the pilot). See the Commands tab for the rest.
