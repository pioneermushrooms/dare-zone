# Foundation source index

- [Dare Zone](https://github.com/pioneermushrooms/dare-zone) contains the public homepage, arena guide, and arena-management plugin.
- [Foundation browser client](https://github.com/pioneermushrooms/dare-client/tree/foundation-browser-parity) contains the shared Dare browser entry point and its WASM build scripts. The current source revision is `74b6d4e265146a84ca2728cf35b4513af18c718d`.
- [Open SubSpace](https://github.com/DangerMouseUK/oss-client) and [SubspaceServer .NET](https://github.com/gigamon-dev/SubspaceServer) are the upstream projects.
